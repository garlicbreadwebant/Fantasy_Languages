# Contributing

Use the existing language folder structure. Cite evidence for vocabulary corrections and specify the English sense. Never invent missing Lingua Ignota grammar or promote an unresolved entry to attested without a source. Distinguish contextual Toki Pona paraphrases and historical Volapük or Solresol variants.

Edit lexicon.csv; run the language checker with --write; rebuild website/data.js; run node website/check-site.cjs. Preserve all 397 English labels in tools/english-headwords.json. Source lists downloaded during research are local scratch files and are not published.
